# Five-minute local demo

Start the server with `python -m contra.server`, then open `http://localhost:8000`.

| Time | Action | What it proves |
| --- | --- | --- |
| 0:00–0:35 | Point out the **SYNTHETIC DEMO MODE** banner. Select ALPHA.NS and Conservative. | Honest provenance and frozen fixture date. |
| 0:35–1:20 | Run analysis; open agent trace and timing. | Three independently executed pipelines with overlapping intervals; each labels model reasoning or deterministic fallback. |
| 1:20–2:05 | Inspect the 20-session return, relative volume, filing tone and price chart. Expand **Show calculation and sources**. | Separate dimensions with dated numeric references. |
| 2:05–2:50 | Open the negative filing excerpt and inspect its exact words, date and hash. | A source-backed research claim and inspectable provenance. |
| 2:50–3:35 | Click **Compare Growth**. | Same market hash and signals; different single-name cap and suitability. |
| 3:35–4:10 | Run DELTA.NS. | No eligible filing by the as-of date; research abstains and the report is partial. |
| 4:10–5:00 | Open Evaluation. Show the measured scenario matrix, Recall@3 and 10-run benchmark. Return to Recent analyses, replay a saved run and export its JSON. | Reproducibility, metrics and persistence. |

The profile editor can change single-name and sector caps. These changes create a new profile revision; existing reports retain the profile snapshot used when they ran.

Demo boundaries: all quantities and filings are simulated. There is no live trading, model inference, future-return accuracy or personalized buy/sell instruction.
